# Sécurité

## Signaler une vulnérabilité

Ne publiez pas de ticket public pour une vulnérabilité. Utilisez le
[signalement privé de GitHub](https://github.com/ElegArtech/codicillus/security/advisories/new) :
décrivez le problème, la version concernée et les étapes pour le reproduire.

Une correction est publiée dans une version de maintenance, accompagnée d'un avis de
sécurité qui crédite l'auteur du signalement s'il le souhaite.

## Versions maintenues

Seule la dernière version publiée reçoit des correctifs de sécurité.
