Une erreur d'envoi se réessaie trois fois, puis se range dans une file d'attente que quelqu'un regarde.

Ce qui n'est jamais regardé n'est pas une file d'attente, c'est une poubelle : la file porte un compteur visible depuis le tableau de bord.
