## 2 · Ce que tu fais, et c'est mécanique

Pour chacune de tes vues, **remplace les imports de constantes par des propriétés OPTIONNELLES**.

```
AVANT :  import { UNIVERS, DOMAINES, MOI, INSTANCE } from '../../seeds/corpus';
APRÈS :  interface Proprietes {
             vecteur: …; notes: readonly Note[];
             univers?: readonly Univers[];      // défaut : UNIVERS
             domaines?: readonly Domaine[];     // défaut : DOMAINES
             compte?: UtilisateurCourant;       // défaut : MOI
             instance?: EtatDInstance;          // défaut : INSTANCE

```

**Les quatre noms ci-dessus sont contractuels** — huit lots les emploieront. Les types sont **ceux de
`seeds/corpus.ts`**, tu n'en déclares aucun nouveau.

**Le défaut est la constante du jeu.** C'est ce qui garantit que **le banc ne bouge pas** : le mode de
conception ne passe rien de nouveau, donc les vues reçoivent exactement ce qu'elles avaient.

**V-15 et V-16 portent `VERSIONS`, `CONTENU_VERSIONS`, `RETENTION_VERSIONS`.** `T-030` a posé la table
